# 팀플 에이전트

> **제15회 컴퓨터학과 소프트웨어 경진대회(2026) 출품작**  
> 팀원마다 붙는 AI 에이전트가 서로 양보하며 회의 시간을 잡고, 회의에서 정한 일을 할 일로 만들고, 마감까지 무엇이 막혔는지 먼저 알려 주는 대학생 팀 프로젝트 도우미

---

## 📌 프로젝트 정보

- **대회**: 제15회 소프트웨어 경진대회 (2026-11-19)
- **형태**: 휴대폰 크기 웹앱 (시연은 노트북 브라우저)
- **기술 스택**: 프론트엔드 React + TypeScript (Vite) · 백엔드 (확정 예정)
- **팀 구성**: 프론트엔드 1명, 백엔드 2명

---

## ✨ 핵심 기능

| 기능 | 설명 |
| :--- | :--- |
| **회의 시간 조율** | 팀원별 에이전트가 각자의 사정을 말하고, 중립 판단 에이전트가 정리해 회의안을 냅니다. 누가 맞춰 줬는지가 양보 기록으로 쌓여 다음 조율에 반영됩니다. |
| **일정 플랜 추천** | 마감일·평가 방식·팀 구성을 넣으면 성격이 다른 플랜 3개를 비교해 고릅니다. 고른 플랜의 단계와 점검일이 일정에 깔립니다. |
| **회의록 → 할 일** | 회의록을 붙여 넣으면 결정·논의·보류로 요약하고, 할 일을 "AI 제안"으로 바로 등록합니다. 사람이 고치거나 확정합니다. |
| **알림** | 늦음, 막힘, 완료, 일 몰림, 단계 지연을 감지해 홈과 알림함에 이유와 함께 보여 줍니다. 회의 30분 전에도 알려 줍니다. |
