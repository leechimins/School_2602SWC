# backend

API 서버와 에이전트(회의 시간 조율, 회의록 요약, 위험 판정) 로직. 스택은 백엔드 담당이 정한 뒤 이 문서에 적습니다.

## 정할 것

- 언어·프레임워크
- 데이터 저장 방식 (시연 규모라면 SQLite 파일이나 메모리 + 시드 데이터로도 충분합니다)
- AI API 호출 방식 (키는 `backend/.env`에만 둡니다)

## 프론트와의 약속

- 주고받는 데이터 모양은 `frontend/src/types/`의 타입을 기준으로 맞추고, 바꿀 때는 PR로 서로 확인합니다.
- 프론트는 서버가 없거나 실패해도 같은 모양의 목 데이터로 화면을 이어 갑니다.
